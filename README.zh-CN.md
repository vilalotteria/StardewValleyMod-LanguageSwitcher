# Language Switcher

*[English](README.md)*

一个星露谷物语（Stardew Valley）SMAPI mod：按一个快捷键，在当前游戏语言和你指定的目标语言之间即时切换。主要给用星露谷学外语的玩家用——切成外语看看菜单/物品/对话怎么说，再切回来对照。

## 功能

- **一键切换语言**（默认 `K`）：在游戏当前语言和你设置的目标语言之间切换，游戏内文字（菜单、物品名、对话等）立即生效，不用重启。两端语言都可自由选择，比如中文 ↔ 意大利语、英文 ↔ 日文都可以
- **对话回放日志**（默认 `L`）：打开一个窗口，按时间顺序显示最近的 NPC 对话，可在原文和译文之间切换查看。由于游戏在文字显示时就已确定语言，已经显示过的对话无法追溯翻译（见下方"已知限制"），这个窗口就是为了解决这个问题——对话结束后随时回看双语对照
- **标题画面配置入口**：标题画面右下角有个 **Language Switch** 按钮，不需要装 GMCM 就能选目标语言、改快捷键、一键恢复默认按键。改按键时会自动拦截与游戏内置操作冲突的键（WASD、方向键、E、F、M、Y、Tab、数字键等）
- **GMCM 支持**（可选）：装了 [Generic Mod Config Menu][gmcm] 的话，也能在游戏内 Mod Options 里配置全部选项

## 依赖

- [SMAPI](https://smapi.io/) 4.5.0 或更高版本
- Stardew Valley 1.6+
- [Generic Mod Config Menu][gmcm]（可选，不装也完全能用，只是少了游戏内菜单这一种配置方式）

## 安装

1. 安装 SMAPI（如果还没装）
2. 把 `LanguageSwitcher` 文件夹整个放进 `Stardew Valley/Mods/` 目录
3. 用 SMAPI 启动游戏

## 使用

- 进入存档后按 **K**：切换语言，右上角会弹一条提示
- 按 **L**：打开对话回放日志。在日志窗口**内**按 K 只切换这个窗口显示原文还是译文，不会改变游戏本身的语言
- 标题画面右下角 **Language Switch** 按钮：选目标语言、改快捷键，不需要 GMCM

### 配置项

在 `config.json`（首次运行后自动生成）、GMCM 菜单、或标题画面的 Language Switch 弹窗里都能改：

| 字段 | 默认值 | 说明 |
|---|---|---|
| `HotKey` | `K` | 切换语言的快捷键 |
| `ReplayLogHotKey` | `L` | 打开对话回放日志的快捷键 |
| `PreferredLanguage` | `zh` | 切换的目标语言：`en`/`ru`/`zh`/`de`/`pt`/`fr`/`es`/`ja`/`ko`/`it`/`tr`/`hu`（与游戏自带的语言列表一致） |
| `ShowNotifications` | `true` | 切换语言时是否显示 HUD 提示 |
| `NotificationDuration` | `3` | 提示显示几秒 |

## 已知限制

这些限制源自游戏本身的文字处理方式：文字在显示的那一刻就已经确定了语言，之后无法追溯改变。

- **切换会等待当前界面结束**：如果按下切换键时有菜单打开（NPC 对话、电视、信件、地图、背包等）或屏幕上有通知提示，切换会自动推迟到它们关闭之后再执行。这样可以保证界面文字始终完整可读，代价是切换有短暂延迟
- **已显示的对话保持原语言**：正在进行或已经看过的对话不会追溯翻译。想查看双语对照，请使用对话回放日志（`L`）
- **分支对话的翻译为尽力而为**：涉及随机分支或玩家选择分支的对话，翻译依赖于能否还原实际触发的那个分支；无法确定时会显示"无翻译"，而不是给出可能错误的内容
